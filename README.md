# veo-prompt-generator

Free Veo 3 / Veo 3.1 prompt generator tool site. Static, no backend, deployed on Cloudflare Pages.

- Site source: `site/`
- Pipeline docs (PRD, pricing, compliance, copy freeze, design, QA): `docs/`
- Project source of truth: `project-control.md`

## Deploy

```sh
npx wrangler pages deploy site --project-name=veo-prompt-generator
```
